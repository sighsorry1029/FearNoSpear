# Build notes

## Target

- Valheim mod
- BepInEx 5
- Harmony / HarmonyX
- .NET Framework 4.7.2 style target (`net472`)

## Required local references

Point `FearNoSpear.csproj` to local copies of:

- `BepInEx.dll`
- `0Harmony.dll`
- `assembly_valheim.dll` or publicized equivalent
- `UnityEngine.dll`
- `UnityEngine.CoreModule.dll`

The user provided publicized assemblies in the original task environment, but this handoff package does not bundle them.

## MSBuild property override

The csproj supports these optional properties:

```bash
msbuild FearNoSpear.csproj /p:ValheimManagedDir="C:\Steam\steamapps\common\Valheim\valheim_Data\Managed" /p:BepInExCoreDir="C:\Steam\steamapps\common\Valheim\BepInEx\core"
```

or with dotnet/msbuild if available:

```bash
dotnet build -c Release /p:ValheimManagedDir=".../valheim_Data/Managed" /p:BepInExCoreDir=".../BepInEx/core"
```

## Publicized assemblies

The draft uses reflection for private Valheim fields and methods, so publicized assemblies are not strictly required for those members. Publicized assemblies may still be useful for decompilation and method-name verification.

## Packaging

For a Thunderstore-style package after compiling:

```text
package/
  icon.png                  # optional, not included in this draft
  manifest.json
  README.md
  BepInEx/plugins/FearNoSpear/FearNoSpear.dll
```

The release package is generated by the project build target.
